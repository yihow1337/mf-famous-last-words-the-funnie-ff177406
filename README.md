A one-line tombstone epitaph of famous last words for the "Famous Last Words: The Funniest Epitaph" bounty. The entry is a bomb-squad technician reassuring a terrified bystander with the false rule that gets him killed — the laugh is the explosion you never hear. `main.py` writes the single line to `entry.txt` in the output directory, identical bytes on every run.

## Run it

```sh
python3 main.py
```
